Projet Web CentraleSupélec — 2026

À propos du projet

Le projet

Dans le cadre du pôle projet « Nouveaux concepts énergétiques » de CentraleSupélec (promotion 2028), 4 étudiants ont repris et continué le développement d'un site initié par le groupe précédent, en collaboration avec l'équipe EDF en charge de l'Open Data.

L'objectif : rendre les données de disponibilité du parc nucléaire français accessibles et lisibles pour tous, à travers une interface web moderne et interactive.

Collecte et traitement des données

Un binôme d'étudiants s'est chargé de récupérer les données brutes auprès des sources officielles ENTSO-E et RTE. Ces données ont ensuite été nettoyées, formatées puis publiées sur la plateforme Open Data d'EDF.

Les données visibles sur ce site proviennent directement de l' Open Data EDF, interrogé via une clé API mise à disposition par l'équipe EDF dans le cadre de ce partenariat.

Source technique

Les données d'indisponibilités par tranche sont accessibles via : RTE Data API. Elles sont actualisées au début de chaque heure.

Publications officielles EDF (règlement REMIT) : EDF REMIT.

Les informations fournies le sont à titre informatif et indicatif. Ce site ne saurait remplacer les publications officielles d'EDF.
